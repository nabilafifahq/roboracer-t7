# June 6 runbook — odom-frame map → 3 laps → best path → pursuit + Berlin plot

Goal: record 3 clean laps in **odom frame** (EKF+IMU stable; Cartographer also running
for the occupancy map), build a best-path raceline, drive it, and make a Berlin-style
"map + best path" figure for the presentation.

## THE ONE RULE
**Terminal 1 (the launch) stays running the WHOLE session.** The `odom` origin is set
when it starts. Record all 3 laps under the SAME launch so they share one frame.
**Relaunching resets odom → the 3 CSVs won't align.** Stop order at the very end:
recorder/pursuit Ctrl+C FIRST, launch Ctrl+C LAST.

Safety: RC on BEFORE car power. Deadman HELD = manual/STOP. Deadman RELEASED = autonomous.

---
## T1 — SSH + container + stack (LEAVE RUNNING ALL SESSION)
```bash
ssh pi@<car-ip>                                   # your Pi
docker pull nabilafifahq/roboracer-t7:cartographer-ekf
export IMAGE=nabilafifahq/roboracer-t7:cartographer-ekf
cd ~/roboracer-t7 && ./scripts/car_run.sh
# --- now inside the container ---
ln -sf /dev/ttyACM0 /dev/sensors/vesc
source /opt/ros/humble/setup.bash && source /race_ws/install/setup.bash
ros2 launch /race_ws/bringup.launch.py autonomy:=none use_cartographer:=true
# leave this running. watch for sensor + cartographer startup, no crash loop.
```

## T2 — health checks (new tab: `docker exec -it roboracer_t7 bash`, then source)
```bash
source /opt/ros/humble/setup.bash && source /race_ws/install/setup.bash
# 1. LiDAR cloud alive (the recurring dropout — must be ~10 Hz):
ros2 topic hz /livox/lidar
# 2. /scan produced from the cloud (let it run a few sec; ~10 Hz). If 0 while
#    /livox/lidar is 10 Hz -> pointcloud_to_laserscan wedged -> Ctrl+C T1 launch, relaunch.
ros2 topic hz /scan
ros2 topic echo /scan --once --field ranges | tr ',' '\n' | grep -vci inf   # want dozens+ finite
# 3. IMU into EKF:
ros2 topic hz /livox/imu
ros2 run tf2_ros tf2_echo base_link livox_frame      # must resolve (static TF)
# 4. EKF odom — THE frame we record in. Drive 0.5 m by RC: must move SMOOTHLY, no jumps:
ros2 run tf2_ros tf2_echo odom base_link
# 5. (optional) Cartographer map frame — for the occupancy map. May teleport on soft hose;
#    that's fine, we log in odom regardless:
ros2 run tf2_ros tf2_echo map base_link
```

ring, come back to the tape, Ctrl+C. Repeat 3×. Do NOT touch T1.

  -p world_frame:=odom -p robot_frame:=base_link -p scan_topic:=/scan -p record_hz:=20.0 \

ros2 run reactive_control manual_map_logger --ros-args \

## T2 — build best path + Berlin plot (in the container, off the driving loop)
```bash
# clean closed raceline from EACH lap (path-as-raceline, always works):
for n in 1 2 3; do
  python3 /race_ws/scripts/path_to_raceline.py /race_ws/logs/lap${n}_june6.csv \
    -o /race_ws/racelines/raceline${n}.csv --plot /race_ws/racelines/raceline${n}.png
done
# Berlin-style map+best-path figure for each (walls from left/right_wall_m + black raceline):
for n in 1 2 3; do
  python3 /race_ws/scripts/presentation_map_plot.py /race_ws/logs/lap${n}_june6.csv \
    -o /race_ws/racelines/map_bestpath_${n}.png --raceline /race_ws/racelines/raceline${n}.csv \
    --max-wall 2.0 --title "UCSD June 6 — lap ${n}"
done
```
Look at the 3 `map_bestpath_*.png`. **Pick the cleanest loop** (closed, no tangle, walls
form the ring). Call it raceline`K`.csv — that's your race line.

## T2 — RUN AUTONOMOUS (same launch still up; deadman in hand)
For continuous laps the pursuit node stops when it reaches the path end (= start of a
closed loop). Triple the chosen raceline so it keeps going:
```bash
K=1   # <-- set to the lap you picked
tail -n +2 /race_ws/racelines/raceline${K}.csv > /tmp/body.csv
{ echo "x_m,y_m"; cat /tmp/body.csv /tmp/body.csv /tmp/body.csv; } > /race_ws/racelines/raceline_run.csv

# start pursuit WHILE HOLDING the deadman (car won't move):
ros2 run reactive_control raceline_pure_pursuit_node --ros-args \
  -p trajectory_csv:=/race_ws/racelines/raceline_run.csv \
  -p world_frame:=odom -p robot_frame:=base_link \
  -p lookahead_m:=0.45 -p wheelbase_m:=0.33 \
  -p target_speed_mps:=0.08 -p max_steering_rad:=0.70 -p stop_within_m:=0.20
```
Order: (1) node up + deadman HELD, confirm no errors. (2) RELEASE deadman → car follows
the line at 0.08 m/s. (3) Squeeze deadman anytime = instant STOP. (4) Done: Ctrl+C the
pursuit node FIRST, then Ctrl+C T1 launch LAST.
