# June 4 runbook — map → raceline → autonomous

Image: `nabilafifahq/roboracer-t7:cartographer-ekf`. Build a closed loop (room corner + 2 hoses + box island); both walls visible everywhere, no side firing out a window.

## Golden safety rules
- **RC ON first, then car power ON.** Always.
- **Deadman HELD = manual / STOP** (RC overrides, priority 100). **Deadman RELEASED = autonomous** (`/drive` takes over).
- **The launch stays running the WHOLE time** (it provides EKF + sensors + localization). Do NOT stop it between mapping and driving — same session keeps the frame consistent.
- **STOP order, always: (1) recorder/pursuit node Ctrl+C → (2) launch Ctrl+C LAST.** Stopping the launch first kills TF and ruins everything.
- Operator watches the car, thumb on deadman, the entire run.

## RUN AUTONOMOUS — exact sequence + deadman
Localization must be live (launch running). Use the frame matching the raceline (`odom` for path A, `map` for B with stable map).
```bash
# T2 (in container) — START the pursuit node WHILE HOLDING the deadman (car won't move):
ros2 run reactive_control raceline_pure_pursuit_node --ros-args \
  -p trajectory_csv:=/race_ws/racelines/raceline.csv \
  -p world_frame:=odom -p robot_frame:=base_link \
  -p lookahead_m:=0.55 -p wheelbase_m:=0.33 \
  -p target_speed_mps:=0.07 -p max_steering_rad:=0.70
```
**Order:**
1. Node started, **deadman HELD** → confirm no errors, car on the line, not moving.
2. **RELEASE deadman** → car follows the line autonomously (0.07 m/s).
3. **Squeeze deadman any time** → instant manual override / STOP.
4. Done: **Ctrl+C the pursuit node FIRST** (it stops commanding), then later **Ctrl+C the launch (T1) LAST**.

> Do NOT stop the launch to "go autonomous" — the launch IS your localization. It stays up. The only thing you start/stop for autonomy is the pursuit node + the deadman.
